# Модерационный Telegram-бот

Удаляет сообщения с запрещёнными словами и наказывает нарушителей
(предупреждение → мут → бан). Вся настройка — кнопками в личке с ботом.

## Установка
```bash
python3.11 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env     # вставьте токен
python main.py
```

## Токен
1. Откройте [@BotFather](https://t.me/BotFather) → `/newbot`.
2. Задайте имя и username (на `bot` на конце).
3. Скопируйте токен в `.env` → `BOT_TOKEN=...`.

## Подключение к группе
1. Добавьте бота в группу/супергруппу.
2. Назначьте его **администратором** с правами:
   - **Удаление сообщений**
   - **Блокировка пользователей** (нужна и для мута, и для бана)
3. Бот отправит каждому админу личное сообщение с кнопкой «⚙️ Настроить бота».
4. **Важно:** Telegram не позволяет боту писать первым тому, кто его не запускал.
   Если ЛС не дошло, бот напишет в группу кнопку-ссылку; можно также
   отправить `/start` в группе — меню придёт в личку.

## Меню настроек
Список слов (удаление ❌), добавление слов, тип наказания
(предупреждение / мут / бан / эскалация), настройки чата
(удалять сообщения админов, длительность мута, уведомления), статистика.

## Как работает поиск слов
- Регистр не важен, «ё» = «е».
- Слово ищется целиком (границы слов): «дурак» ловится в «ты дурак!»,
  но не в «дуракафе».
- «дурак*» ловит и окончания (дураки, дураками…).
- Допускаются фразы из нескольких слов.

## Ограничения Telegram
- Сообщения старше 48 часов удалить нельзя — бот пропускает такие (актуально
  для редактирования старых сообщений).
- Админы чата не наказываются. Включённая опция «удалять сообщения админов»
  только удаляет сообщение.
- Анонимные админы и сообщения от имени каналов игнорируются.

## Переподключение и остановка
Polling автоматически переживает обрывы сети (backoff); при недоступности
Telegram на старте бот повторяет попытки. `Ctrl+C` / SIGTERM — штатная остановка
с закрытием БД.

## Запуск как сервис (systemd)
```ini
[Service]
WorkingDirectory=/opt/modbot
ExecStart=/opt/modbot/.venv/bin/python main.py
Restart=always
```
